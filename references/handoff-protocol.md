# 个人交接协议（Handoff）

## 为什么需要它

你在不同 AI 里聊过的东西，是散的。每换一个助手，就要从头讲一遍，讲累了你就不讲了。
这份协议的作用：**让上一个 AI 把你已经说过的话，整理成一份「可交接的档案」**，而不是让你重新做一遍自我介绍。

交接的不是聊天记录，是**已经被整理过的、区分了事实与推测的画像**。

## 什么时候用

- 第一次把罗盘介绍给你时
- 你刚和一个 AI 深聊过（关于专业、未来、家庭、感情、自我怀疑）
- 每隔 1–2 个月，更新一次
- 你觉得「又要重新讲一遍」很烦的时候

## 隐私提醒（先跟你说）

1. 交接文档是给**你自己看的**。分享给罗盘之前，先读一遍。
2. 让上一个 AI 把人名、公司、学校、住址、账号、病情等用 `[已隐去]` 代替。
3. 不想说的可以删。删掉不影响使用，只是画像会少一块。
4. 罗盘的数据只存在本机，不上传。

## 完整交接提示词（对话已经比较多时用）

<!-- PROMPT:START -->
我要把和你的聊天交接给另一个助手，让它不用从头问我，就能理解我。请你只根据我们过去的对话，整理一份「个人交接文档」。

规则：
1. 只写对话里有依据的内容。没有依据的写「未提及」，不确定的标「不确定」。不要推测、不要补全、不要替我说我没说过的话。
2. 区分「我明确说过的事实」和「你的观察/推断」。推断必须标出来。
3. 涉及具体人名、公司、学校、住址、账号、疾病、家庭矛盾等敏感信息，用「[已隐去]」代替。
4. 不要评价我，不要给建议，不要下结论。只做整理。
5. 如果某个部分对话里几乎没有内容，就写「信息不足」，不要编。
6. 用下面的结构输出，最后附一个 JSON 摘要。

# 个人交接文档

## 1. 基本信息
（年龄/阶段/学校专业/所在城市/家庭大致情况。只写我明确说过的）

## 2. 我在意什么
（我主动聊起、反复提起、做起来忘记时间的事。每条附上对话里的依据）

## 3. 我擅长什么
（有具体例子支撑的。没有例子的写「自称，未验证」）

## 4. 我讨厌什么 / 回避什么
（包括工作状态、人际方式、被对待的方式）

## 5. 我的处境和约束
（钱、城市、家庭期待、身体/情绪、时间。只写我说过的）

## 6. 我试过什么，结果如何
（课程、社团、比赛、兼职、自媒体、实习、自学。写做了什么、结果、我的感受）

## 7. 我反复纠结的问题
（原话优先。不要替我归纳成一个漂亮的问题）

## 8. 我对未来的想象
（包括我想要的、我害怕的、我不敢说的）

## 9. 我希望别人怎么跟我说话
（我讨厌被说教/被安慰/被催吗？我希望直接还是委婉？）

## 10. 你还不知道、但值得问我的 10 个问题
（按重要性排序，每个问题说明为什么值得问）

## 11. 机器可读摘要
```json
{
  "facts": {"name": "", "age": "", "school": "", "major": "", "grade": "", "city": "", "family_context": "", "money_pressure": "", "health": ""},
  "interests": [{"name": "", "evidence": "", "energy": "高/中/低", "confidence": "确认/猜测"}],
  "strengths": [{"name": "", "evidence": "", "confidence": "确认/猜测"}],
  "values": [{"name": "", "rank": 1, "note": ""}],
  "dislikes": [{"name": "", "evidence": ""}],
  "constraints": [{"name": "", "type": "家庭/经济/城市/身体/时间", "note": ""}],
  "experiments": [{"title": "", "date": "", "did": "", "result": "", "energy": "", "learned": ""}],
  "questions": [{"q": "", "status": "open"}],
  "preferences": {"tone": "", "avoid": []}
}
```

## 对话不多时：先访谈，再交接

<!-- INTERVIEW:START -->
我想请你先访谈我，再帮我整理一份可以交接给另一个助手的个人文档。

访谈规则：
1. 一次只问一个问题，等我回答后再问下一个。总共不超过 20 个问题。
2. 问具体的事，不要问抽象的概念。比如不要问「你的价值观是什么」，问「上一次你为了做一件事主动熬夜，是什么事」。
3. 不评价、不建议、不安慰，只追问细节。
4. 我可以说「不想回答」，跳过就好。
5. 问完后，按下面的结构输出交接文档。

访谈方向（不必按顺序）：
- 最近一年，什么事让你忘记时间？什么事让你觉得时间过得特别慢？
- 你做过什么，别人夸过你，而你自己也觉得「这确实是我擅长的」？
- 你最受不了被怎样对待？
- 你现在最怕的是什么？最想要的又是什么？
- 家里对你有什么期待？你怎么看这些期待？
- 你做过的某个决定，现在回头看是对的/后悔的？
- 如果接下来半年只能验证一件事，你会选什么？
- 你羡慕谁？羡慕 TA 什么？
- 你觉得自己被什么卡住了？
- 有没有什么事，你一直想做但没开始？为什么没开始？

输出结构：
# 个人交接文档
（1. 基本信息 / 2. 我在意什么 / 3. 我擅长什么 / 4. 我讨厌什么 / 5. 处境和约束 / 6. 试过什么 / 7. 反复纠结的问题 / 8. 对未来的想象 / 9. 希望别人怎么跟我说话 / 10. 你还不知道但值得问的问题）

最后附一个 JSON 摘要，字段同「完整交接」的第 11 部分。
<!-- INTERVIEW:END -->

## 导入 Compass

把 AI 输出的整份文档存成 `.md`，让 agent 读，然后把内容写进服务：

```bash
compass profile --set name=... --set school=... --set major=...
compass self --merge '{"interests":[...],"strengths":[...],"values":[...]}'
compass stories --add '{"title":"...","bullets":["..."]}'
```

- 只写有依据的内容；不确定的标「猜测」或先不写。
- 写完让 agent 复述 5 条，问「哪条不对」。
- 服务会保留版本和更新时间，不需要手动备份。

## 导入之后

让 agent 先做一件事：**把导入的内容复述一遍**，问你「哪条不对、哪条是你当时没说清楚的」。
交接文档是上一个 AI 的理解，不是你本人。**必须经过你确认，才能当成事实使用。**

## 多久更新一次

- 每次深聊之后：不用重新导入，让 agent 用 `self.py` 增量补
- 每 1–2 个月：重新跑一次完整交接，对比变化
- 你换了主要使用的 AI：跑一次

## 如果上一个 AI 不配合

- 它可能不会输出 JSON：没关系，只要正文结构对，agent 能读
- 它可能写得像心理测评：告诉你「这份不像我」，然后只保留准确的部分
- 它可能拒绝谈敏感话题：换一个 AI，或者用访谈版重新来
