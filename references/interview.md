# 面试准备（实习岗）

## 先判断面试类型

- **HR 初筛**（10–20 分钟）：到岗时间、能做什么、稳定性、薪资预期。
- **业务面**（30–45 分钟）：JD 里的具体工作、你的相关经历、现场小任务。
- **老板/创始人面**（小公司常见）：为什么来、能待多久、主动性。

## 必答的 4 个问题

1. **自我介绍（60–90 秒）**
   结构：我是谁 → 我做过一件和这个岗位相关的事 → 我能到岗的时间 → 为什么是这家。
   不要背简历，只讲一条主线。

2. **你为什么想来我们公司 / 这个岗位？**
   必须提到具体的东西：产品、业务、JD 里的一条职责、你用过的东西。
   反例：「贵公司平台大、发展好」。

3. **你做过的最有成就感的一件事？**
   STAR：情境一句 → 你的动作两句 → 结果一句（数字优先）。
   大二没有实习，就讲课程项目/社团/比赛/自媒体。

4. **你还有什么问题？**
   问工作内容、团队、考核方式、转正机制。
   不要第一句问薪资和加班。

## 按 JD 生成问题

从 JD 里抽 3 类词：
- **业务对象**（用户、内容、数据、活动、客户）
- **动作**（分析、策划、运营、对接、整理）
- **工具**（Excel、SQL、剪映、小红书后台）

每个词配一个「你做过类似的吗 / 你会怎么做」的问题，提前写答案。

## 面试后 10 分钟

```bash
compass jobs advance --id <id> --to interview --note "问了X/Y/Z；我答得不好的地方：..."
```

把答不好的问题记下来，下次面试前看一遍。

## 反问清单

- 这个实习生进来后，前两周具体做什么？
- 团队现在最缺的能力是什么？
- 实习生有转正/留用机会吗？往年的比例大概多少？
- 我需要在入职前补什么？
