# 职业地图（给没背景的普通本科生）

> 用途：扫盲，不是推荐。每条只回答：日常做什么、门槛、大概收入、适合谁、风险。
> 收入是 2026 年公开信息的大致区间，城市/公司/行业差异很大，**只用来建立数量级直觉，不要当承诺**。

## 先看这张表

| 大类 | 典型岗位 | 入门门槛 | 起薪量级（月） | 3–5 年后的分叉 |
|---|---|---|---|---|
| 稳定型 | 公务员、事业编、国企、教师、银行 | 考试/证书/校招 | 4–10k（地区差异极大） | 稳定但晋升慢；部分岗位市场化 |
| 商业型 | 运营、市场、销售、人力、财务 | 实习 + 沟通/工具 | 5–12k | 运营→操盘手；销售→大客户；HR→HRBP |
| 产品型 | 产品经理、产品运营、用户研究 | 实习 + 逻辑/沟通 | 6–15k | 产品→业务负责人；门槛在收紧 |
| 数据型 | 数据分析、BI、数据运营 | SQL/Excel/统计 + 项目 | 6–14k | 分析→业务分析/数据产品 |
| 技术型 | 开发、测试、运维、算法 | 项目/算法/实习 | 7–20k+ | 分化最大；非科班靠项目补 |
| 创意型 | 设计、内容、新媒体、视频、游戏 | 作品集 | 5–12k | 作品说话；自由职业比例高 |
| 服务型 | 教育、医疗、心理、社工、旅游 | 专业/证书 | 4–10k | 稳定但强度高；部分需深造 |
| 深造型 | 考研、保研、留学、第二学位 | 成绩/考试/钱 | 负收入或奖学金 | 学历提升，但延迟进入市场 |
| 自由型 | 自媒体、电商、接单、自由职业 | 作品/流量/供应链 | 波动极大 | 上限高、下限低，需现金流 |
| 公益型 | NGO、公益项目、国际组织 | 语言/项目/志愿经历 | 4–8k | 稳定但窄；需长期投入 |

## 稳定型

**公务员 / 事业编**
- 日常：写材料、办流程、对接上下级、应对检查。稳定、边界清晰，但自主性低。
- 门槛：行测 + 申论 + 面试；岗位限制专业、户籍、应届身份。
- 收入：地区差异极大，同一职级不同城市能差一倍。
- 适合：看重稳定、能接受层级和流程、写作能力尚可。
- 风险：备考周期长（6–12 个月），一次上岸率低；上岸后调岗空间有限。

**教师 / 银行 / 国企**
- 教师：师范/教资 + 考编；寒暑假是真实优势，但班主任强度高。
- 银行：校招为主，柜员→客户经理；指标压力真实存在。
- 国企：行业差异极大，垄断型与竞争型完全两种体验，**入职前一定问清子公司和岗位**。

## 商业型

**运营**
- 日常：内容、活动、用户、社群、数据复盘。是「用各种手段让一个业务指标变好」。
- 门槛：实习 + 会写/会沟通/会看数据；作品比证书有用。
- 适合：反应快、愿意和人打交道、能接受琐碎。
- 风险：初级运营容易被替代；要尽早往「能对结果负责」的方向走。

**市场 / 销售**
- 市场：品牌、投放、活动、公关，花钱的部门，经济下行时先被砍。
- 销售：最不看背景的岗位之一，收入上限高，但淘汰率也高；To B 销售更看行业知识。
- 适合：抗压、脸皮厚、目标感强；不适合讨厌被拒绝的人。

**人力 / 财务**
- 人力：招聘、培训、薪酬、员工关系；入门容易，做深难。
- 财务：证书（初级/CPA）+ 细心；越老越吃香，但前期枯燥。

## 产品型

- 日常：发现问题、写需求、拉齐研发设计、上线、看数据。是「对结果负责但没有直接指挥权」的角色。
- 门槛：实习 + 逻辑 + 沟通 + 一点数据；现在校招竞争很激烈，非名校要靠项目和实习。
- 适合：喜欢拆问题、能承受模糊、愿意协调人。
- 风险：初级产品供大于求；「产品经理」三个字被过度浪漫化。

## 数据型

- 日常：取数、清洗、做报表、解释指标、支持业务决策。统计/数学/计算机背景都可。
- 门槛：SQL + Excel + 统计基础 + 一个能讲清楚的项目。
- 适合：坐得住、对数字敏感、能把业务问题翻译成数据问题。
- 风险：只做取数会被工具替代；要往「业务分析/数据产品」走。

## 技术型

- 日常：写代码、改 bug、评审、上线。细分方向差异极大。
- 门槛：项目 + 基础（数据结构/网络/数据库）；非科班可以用作品补，但需要时间。
- 适合：能长时间专注、愿意持续学习。
- 风险：技术更新快；只会在一个框架里 CRUD 的岗位在减少。

## 创意型

- 日常：设计/写作/剪辑/策划，作品就是简历。
- 门槛：作品集 + 审美 + 工具；学历权重相对低。
- 适合：表达欲强、能接受反复修改。
- 风险：收入不稳定；版权/平台规则风险；「爱好变工作」后可能失去乐趣。

## 深造型

**考研**
- 适合：想换专业/换学校层次、目标岗位硬性要求硕士、能承受 6–12 个月高强度备考。
- 不适合：只是不想面对就业；没有明确专业方向；家庭现金流紧张。
- 关键问题：**考完想解决什么问题？** 如果答不上来，先工作一年再考也不迟。

**留学**
- 成本：学费 + 生活费，国家差异极大；需要语言成绩和申请材料。
- 回报：学历 + 语言 + 视野 + 可能的海外工作机会；不等于自动高薪。
- 风险：家庭负债、回国就业竞争、专业不匹配。

## 自由型

- 自媒体/电商/接单：上限高、下限低，需要现金流支撑。
- 建议：**先兼职验证，不要裸辞 all in**；用 3–6 个月测试能否稳定获得第一笔收入。
- 关键能力：获客、交付、复购，而不是「会做内容」。

## 怎么用这份地图

1. 先选 3 个**你完全不了解**的方向，各读 5 个真实 JD。
2. 每个方向找一个从业者聊 20 分钟（学长学姐、校友、小红书/知乎私信）。
3. 记录：日常最无聊的部分是什么？最难受的部分是什么？我能不能忍受？
4. 排除法比选择法更可靠。**先排除「确定不要」的，剩下的再试。**

## 信息可信度

- 薪资：招聘平台标价通常偏高，问在职的人到手多少更准。
- 前景：行业报告有滞后，看最近 12 个月的招聘量变化。
- 「XX 专业只能做 XX」：绝大多数是假的。专业限制的是入口，不是天花板。
