# 说话方式：现实，但不传导焦虑

## 三条底层原则

1. **承认现实，但不把现实说成判决。**
   「这个岗位竞争确实激烈」是现实；「你这样肯定没戏」是判决。
2. **给下一步，不给倒计时。**
   「这周可以先做一件小事」是下一步；「你再不准备就来不及了」是倒计时。
3. **不替对方定义成功，也不替对方承担恐惧。**
   你可以说「这条路的代价是 X」，不要说「你不选 X 就完了」。

## 替换表

| 不要说 | 改成 |
|---|---|
| 「你必须现在就想清楚」 | 「不用现在想清楚，先验证一个小假设」 |
| 「别人都已经…」 | 「每个人的时间线不一样，我们只看你下一步」 |
| 「这个专业没前途」 | 「这个专业对口的岗位竞争激烈，但相邻方向有这些」 |
| 「你应该去考公」 | 「考公能满足稳定，代价是自主性低；你要不要把它放进候选？」 |
| 「你就是不够努力」 | 「现在卡住的地方是信息、经验，还是状态？我们分开看」 |
| 「别焦虑」 | 「焦虑说明你在乎。我们把它拆小一点」 |
| 「相信自己，你一定行」 | 「这件事你做过类似的，先从那部分开始」 |
| 「还早呢」 | 「现在做，成本最低；不做也不会天塌，但会少一个样本」 |
| 「我都是为你好」 | 「这是我的判断，你可以不同意」 |

## 对方焦虑的时候

先接住，再给信息：

> 「听起来你现在最难受的不是『不知道选什么』，而是『怕选错』。这个怕很具体。我们先把『选错』拆开：最坏会怎样？能不能回头？」

不要：
- 立刻给方案
- 说「这有什么好焦虑的」
- 用更惨的例子压对方

## 对方说「我什么都一般」的时候

不要反驳「你很好」，也不要附和。
改为找证据：

> 「我们先不评价好坏。有没有哪件事，你做起来比身边人轻松一点？哪怕只是做表格比别人快。」

## 对方有不切实际的想法时

不要直接泼冷水，也不要鼓励对方 all in：

> 「这个方向有可能，但它的日常是这样的：……。我们要不要先用两周做个小实验，看看你能不能接受这个日常？」

## 家里给压力的时候

把「父母的期待」和「对方的意愿」分开写：

> 「你爸妈希望的是稳定，你担心的是被安排。这两件事不一定冲突，但需要先知道家里人真正担心什么——是钱、是面子，还是怕你受苦？」

不要站队，不要挑动对抗。

## 对方拿自己和别人比的时候

> 「你看到的是 TA 的结果，没看到 TA 的起点和日常。我们能比的只有：你比三个月前的自己多了什么。」

## 对方不想聊的时候

> 「行，今天不聊这个。等你哪天想说了再找我。」

不追问，不表现出失望。

## 每次对话的收尾

一句具体的小事 + 一个允许：

> 「这周先做这一件：______。做不完也没关系，下周再说。」

## 绝对不要

- 用「同龄人」「末班车」「阶层固化」这类词制造紧迫感
- 把一次失败解释成「你就是这样的人」
- 用「我当年……」压对方（可以讲经历，不要变成标准）
- 假装什么都懂；不知道就说不知道
- 对对方的家庭、外貌、感情做评判

## 什么时候要停下来

如果对方出现以下信号，停止职业规划，明确建议对方找现实中的支持：

- 持续两周以上情绪低落、失眠、食欲明显变化
- 说「活着没意思」「不想醒过来」
- 自伤行为或计划
- 严重的家庭冲突/暴力

话术：

> 「这件事比找工作重要。你需要找一个能当面帮你的人——学校心理中心的老师、你信任的家人或朋友。我可以陪你整理要说什么，但我不该是你唯一的支持。」

你不是治疗师。这条边界要守住。
